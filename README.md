## نظرة عامة

**Sakan 4U** منصة عربية موجهة للسكن الطلابي، تساعد الطلاب على اكتشاف العقارات المناسبة وطلب معاينتها ضمن تجربة واضحة وآمنة. تجمع المنصة بين الطلاب والملاك المعتمدين، وتدعم مراجعة إدارية للإعلانات والمستندات الخاصة قبل إتاحة العقارات للعامة، مع حماية بيانات الموقع والوثائق الحساسة.

## المزايا الرئيسية

### 🎓 للطلاب

- **بحث وتصفية متقدمان** حسب المنطقة، نوع السكن، السعر، السعة، التجهيزات ومدى الملاءمة.
- **العقارات المفضلة** لحفظ الخيارات ومقارنتها لاحقاً من مساحة خاصة بالحساب.
- **إعلانات موثّقة** تخضع لمراجعة إدارية قبل ظهورها في الاستكشاف العام.
- **طلبات معاينة آمنة** مع منع الطلبات المكررة، وحالات متابعة واضحة، وإقرار إلزامي بشروط المعاينة والتنسيق.

### 🏠 للملاك

- **إضافة عقار بخطوات واضحة** تشمل الموقع الخاص، البيانات الأساسية، والتجهيزات والصور.
- **ضغط الصور في المتصفح** قبل الرفع لتقليل استهلاك البيانات والتخزين مع الحفاظ على تجربة رفع واضحة.
- **تنسيق طلبات المعاينة** وإدارة الصور وحالة الإعلان من مساحة المالك.
- **تحقق هوية خاص** عبر بطاقة شخصية إلزامية ومستند ملكية اختياري؛ لا تظهر هذه الملفات للعامة.

### 🛡️ للإدارة

- **لوحة متابعة إدارية** لإحصاءات المنصة، مراجعة العقارات، وإدارة طلبات المعاينة.
- **تحقق KYC خاص** لمراجعة مستندات هوية الملاك ومستندات الملكية عبر صلاحيات إدارية مقيدة.
- **إدارة الأرشفة الآمنة** للعقارات بدلاً من الحذف المباشر، مع الحفاظ على السجل التشغيلي والحجوزات المرتبطة.
- **روابط واتساب سريعة** لتنسيق طلبات المعاينة مع الأطراف المصرح بالوصول إلى بياناتها.

## التقنيات المستخدمة

| المجال | التقنيات الأساسية |
|---|---|
| الواجهة | React 19، Vite 7، Wouter، Tailwind CSS 4، TanStack Query |
| الخادم | Node.js، Express، tRPC، Zod |
| المنصة الخلفية | Supabase PostgreSQL، Supabase Auth، Supabase Storage، Row Level Security |
| الجودة | TypeScript، Vitest، ESLint/تنسيق المشروع عبر أدوات الحزمة |
| الوسائط | ضغط صور في المتصفح، تخزين خاص للمستندات، ومسار نشر صور مُدار |

## البدء محلياً

### المتطلبات

- Node.js 22 أو أحدث.
- `pnpm` 10 أو أحدث.
- مشروع Supabase مُعدّ مع الجداول وRLS وStorage migrations الموجودة في `supabase/migrations`.

### التثبيت والتشغيل

```bash
git clone https://github.com/amrabdeltawab-dev/sakeno-mvp.git
cd sakeno-mvp
pnpm install
```

أنشئ ملف بيئة محلياً مثل `.env.local` أو اضبط متغيرات البيئة في بيئتك التشغيلية. **لا تضع مفاتيح حقيقية في Git.**

```bash
# Supabase (القيم الفعلية مطلوبة ولا تُنشر)
VITE_SUPABASE_URL=
VITE_SUPABASE_PUBLISHABLE_KEY=
SUPABASE_SERVICE_ROLE_KEY=

# جلسات الخادم والتكاملات المعتمدة عند الحاجة
JWT_SECRET=
SUPABASE_BOOTSTRAP_SUPER_ADMIN_EMAIL=
```

شغّل خادم التطوير:

```bash
pnpm dev
```

ثم افتح التطبيق من الرابط الذي يعرضه الخادم المحلي. للتحقق قبل الإنتاج، شغّل:

```bash
pnpm test
pnpm check
pnpm build
```

## مبادئ الحماية والخصوصية

يعتمد Sakan 4U على **Supabase Auth** للتحقق من الجلسات، و**RLS** لتقييد الوصول إلى البيانات حسب الدور والملكية، وStorage خاص للمستندات الحساسة. لا تظهر مستندات التحقق أو الإحداثيات الدقيقة للعقار ضمن استجابات الاستكشاف العام.
